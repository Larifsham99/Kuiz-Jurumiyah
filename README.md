# Kuiz-Jurumiyah
Hub Matan Al-Jurumiyyah ialah aplikasi kuiz interaktif berkonsepkan arked islamik untuk menguji kefahaman asas ilmu Nahwu secara santai. Sesuai untuk semua tahap pelajar, dilengkapi efek bunyi, animasi, dan senarai juara. Dibangunkan dengan kredit dedikasi khas buat Pondok Lanai Madrasah Misbahul Falah. Mari santai belajar ilmubahasa Arab
